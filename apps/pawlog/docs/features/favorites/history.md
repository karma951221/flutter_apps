| 판단 | 이유 |
|---|---|
| `setFavorite` 는 `updated_at` 을 바꾸지 않는다 | 기록 내용을 고친 것이 아니다 |
| `UpdateWalkScenario` 가 돌려주는 `Walk` 에 `isFavorite` 를 넘긴다 | 수정 뒤 화면이 별을 잃지 않게(DB 값은 원래 맞았다) |
| 별 토글은 결과를 기다려 화면을 바꾸고, 실패면 스낵바 · 별 그대로. 진행 중 다시 누르기는 무시 | 낙관적 갱신보다 단순하고 로컬 쓰기라 빠르다 |
| 필터는 화면 상태 — 앱을 다시 열면 전체 | 계획 결정 #5 |
| 이번 주 요약 줄 · 통계는 필터와 무관하게 전체 | 계획 결정 #6 |
| 필터 중이어도 산책이 아예 0건이면 즐겨찾기 안내가 아니라 첫 산책 안내 | "기록이 하나도 없다" 가 더 중요한 사실이다(최종 리뷰 Minor 1) |

## 넘기는 것 (최종 리뷰 Minor)

- 목록 실패 중에는 메뉴 문구가 "즐겨찾기만 보기" 로 돌아간다(다시 시도하면 필터 유지)
- 별 저장 중 삭제가 시작됐다 실패하면 화면 별이 저장값과 어긋날 수 있다(로컬 쓰기라 사실상 없음)
- 피드 카드의 별에 스크린리더 라벨이 없다 · 삭제 중 상세 별이 비활성 색으로 보이지 않는다
