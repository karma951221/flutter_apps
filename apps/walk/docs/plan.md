## 목적

생활에 필요한 작은 도구를 하나의 앱에 모은다. 표시 이름은 **Life Tool**(폴더 · 패키지는 `walk`).
지금 도구는 셋이다.

- **걷기** — 오늘 걸음을 앱을 열자마자 보고, 이번 주 · 이번 달을 막대그래프로 본다. 걸음은 앱이
  세지 않고 Health Connect 에서 읽는다.
- **알람** — 기상용 알람. 걸음과 연동하지 않는다. 잠금 화면 위로 울리고, 재부팅 · 시간대 변경 뒤에도
  제 시각에 울린다.
- **일기** — 짧은 기록을 스토리로 묶어 쓰는 개인 일기장. 알람 · 걷기와 연동하지 않는다. 사진 · 짧은 영상 ·
  위치 · 해시태그를 붙이고 스토리 동그라미 · 피드 · 뷰어로 돌아본다. 일기 탭만 PIN · 패턴으로 잠근다.

안드로이드만, 로그인 · 백엔드 없음.

## 화면

하단 탭 셸 `MainShellPage` — [알람 · 걷기 · 일기 · 설정], 첫 탭은 **걷기**. 탭마다 자기 `Scaffold` 를 두고
`IndexedStack` 으로 탭을 오가도 상태가 남는다. 라우터 없음(푸시 화면은 알람 편집 · 울림과 일기 화면들 ·
잠금 설정). 일기 화면은 모두 `pushDiaryRoute` 로 열어 셸의 일기 잠금 게이트를 함께 씌운다.

### 걷기

- 접근 상태(Health Connect 없음 · 업데이트 필요 · 권한 없음)는 탭 전체를 `AppPlaceholder` 로 대신하고
  설치 · 권한 요청 버튼을 준다.
- 앱 열 때 · 백그라운드 복귀 때 · 당겨서 새로고침 때 다시 읽는다.
- 걸음만 읽는다. 거리 · 칼로리는 실제 폰에서 오지 않아 뺐다(2026-10-21).
- **하루 목표**(기본 10,000, 설정에서 변경)는 앱 전역 `StepGoalCubit` 이 들고 `AppSettings` 에 저장한다.
  오늘 카드의 링은 목표 대비 비율을 채우고(넘치면 꽉 찬 채), 아래 줄은 남은(넘친) 걸음이다.
- 목표를 채우면 배지 · 초과 걸음 문구와 함께 축하 연출(햅틱 포함)을 **날짜당 한 번** 한다.
  본 날짜는 `AppSettings` 에 남겨 다시 열어도 되풀이하지 않는다.
- 그래프는 목표선을 긋고 높이 기준을 `max(최댓값, 목표)` 로 한다. 달성한 날은 진한 막대.
  값을 읽는 동안 오늘 카드와 기간 영역은 스켈레톤을 보인다. 애니메이션 끄기면 연출을 생략한다.

### 알람

- 알람 정의는 벽시계 시각(시 · 분 · 반복 요일)으로 저장한다. 반복이 없으면 1회성.
- 앞으로 **14일 안의 회차를 미리 예약**하고, 앱 시작 · 복귀 · 저장/삭제/토글 · 울림 뒤에 다시 맞춘다
  (`sync`). 그래서 앱을 14일 넘게 열지 않으면 반복 알람이 멈출 수 있다(설정 탭 안내).
- 남은 시간은 **실제로 예약된 다음 울림** 기준이다(스누즈 포함). 분 단위, 올림. 매분 0초에 갱신.
- 울림:
  - 화면 꺼짐 · 잠금 → 전체 화면 울림 화면
  - 폰 사용 중(다른 앱이 앞) → 상단 헤드업 알림에 같은 두 버튼
  - 이 앱이 앞 → 앱 안에서 울림 화면
- 스누즈는 5분 고정. 울리는 중 앱을 최근 앱에서 밀어도 계속 울린다.
- 재부팅 뒤에는 패키지가 예약을 되살린다. 시간대가 바뀌면 수신기가 예약을 새 시간대의 같은 벽시계
  시각으로 옮긴다.
- 권한은 알람을 처음 저장/켤 때 묻는다(알림 → 정확한 알람). 거부해도 저장하고 경고 배너를 둔다.
- 저장값이 깨졌으면 읽을 수 있는 알람만 살리고 원본은 백업 키에 남긴다.
- 요약 카드는 초록 컨테이너 색, 꺼진 알람 행은 흐린 글자, 스위치에 햅틱. 울림 화면은 시각 뒤로 파동이 퍼진다(애니메이션 끄기면 정지).

### 일기

- 기록은 반드시 **스토리** 하나에 속한다. 기본 스토리 "일상"은 앱이 만들고 닫기 · 삭제할 수 없다(이름 · 표지만).
  스토리는 열린 것 여럿이 동시에 있을 수 있고, 닫은 것은 보관함으로 가며 다시 열 수 있다.
- 일기 탭은 스토리 동그라미 줄과 모든 스토리의 기록 피드 하나다(보기 모드 · "고른 스토리" 없음). 동그라미를 누르면 인스타식 스토리 뷰어가 열린다.
  진행 중 스토리는 마지막 날부터, 닫힌 스토리는 첫날부터 보고, 하루가 막대 하나다. 피드 영상은 자동재생하지 않는다. 화면 구성 · 판단은 [화면 재기획 설계](../../../docs/superpowers/specs/2026-10-21-walk-diary-story-redesign-design.md) 와 [기록](history.md#2026-10-21--일기-화면-재기획).
- 작성: 기본 스토리는 열린 것 중 최근에 기록을 넣은 것. 시각은 미래 불가, 과거로 바꾸면 현재 위치를 빼고 장소 이름을
  직접 넣으며 그 시각이 기간에 드는 열린 스토리를 제안한다. 수정 중 시각을 바꿔도 저장된 위치는 그대로다.
  닫힌 스토리에 새 기록은 못 넣지만, 기존 기록을 닫힌 스토리로 옮길 수는 있다.
- 미디어: 고르는 즉시 임시 폴더에 압축 사본(사진 긴 변 1600px · JPEG 85 · EXIF 제거, 영상 최대 720p · 30초 이하 ·
  썸네일)을 만들고 저장할 때 정식 폴더로 옮긴다. 원본은 건드리지 않는다. 한 번에 하나씩 가져온다.
- 위치: 작성 화면을 열 때 현재 위치를 구해 장소 이름(`locality` · `subLocality` · `thoroughfare` 중 비지 않은 앞의 둘)을 붙인다. 권한 거부 · 실패면 위치 없음.
  이름을 못 얻으면(오프라인) 좌표만 저장하고, 탭에 들어올 때 정리(`maintain`)가 한 번에 20곳까지 다시 묻는다.
- 태그: 칩 입력. `#` · 공백 · 대소문자만 다른 입력은 하나다(최대 30자).
- 검색: 300ms 디바운스. 글은 부분 일치(`%` · `_` · `\` 는 글자 그대로), 스토리 · 태그 · 장소는 추천과 기록 수.
  빈 입력이면 글 · 스토리는 조회하지 않고, 태그 · 장소는 상위 추천을 보인다.
- 삭제는 휴지통으로. 보관 기간(1 · 7(기본) · 30일 · 안 함)이 지나면 탭 정리 때 미디어 파일 · 태그 연결까지 지운다.
  스토리를 지우면 그 기록은 휴지통으로 가고, 복원하면 "일상"으로 돌아온다. 앱 시작 때 DB 에 없는 고아 파일을 치운다(24시간 유예).

### 일기 잠금

- 설정에서 켠다. 폰에 화면 잠금이 있어야 한다. PIN 4자리 또는 패턴(점 4개 이상, 건너뛴 가운데 점 자동 포함)을 두 번 입력.
  비밀은 랜덤 salt + SHA-256 10,000번 반복 해시로만 남는다.
- 앱 시작 때 잠김. 백그라운드에서 다시 잠기는 시간(즉시 · 30초 · 1분(기본) · 5분)을 넘기고 돌아오면 다시 잠근다.
  사진 · 영상을 고르러 나간 동안은 세지 않는다. 시계가 거꾸로 가면 잠근다.
- 잠긴 동안 기록 위젯은 트리에 없다. 다시 잠기면 일기 위의 시트 · 다이얼로그를 닫고, 쓰던 글은 메모리에 남아 풀면 돌아온다.
  잠긴 동안에는 정리 · 휴지통 기간 · 다시 잠기는 시간 바꾸기를 막는다.
- 5번 틀리면 30초 차단. "잊어버렸어요" → 폰 인증 성공이면 새 비밀 등록, 실패(폰 쪽 잠김 포함)면 24시간 모든 해제 시도 차단.
  인증 창을 닫는 것은 실패가 아니다. 실패 횟수 · 차단은 재시작 뒤에도 남는다.
- 알람 울림 화면은 일기 잠금과 무관하게 뜬다.
