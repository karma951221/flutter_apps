## 목적

생활에 필요한 작은 도구를 하나의 앱에 모은다. 표시 이름은 **Life Tool**(폴더 · 패키지는 `walk`).
지금 도구는 둘이다.

- **걷기** — 오늘 걸음을 앱을 열자마자 보고, 이번 주 · 이번 달을 막대그래프로 본다. 걸음은 앱이
  세지 않고 Health Connect 에서 읽는다.
- **알람** — 기상용 알람. 걸음과 연동하지 않는다. 잠금 화면 위로 울리고, 재부팅 · 시간대 변경 뒤에도
  제 시각에 울린다.

안드로이드만, 로그인 · 백엔드 없음.

## 화면

하단 탭 셸 `MainShellPage` — [알람 · 걷기 · 설정], 첫 탭은 **걷기**. 탭마다 자기 `Scaffold` 를 두고
`IndexedStack` 으로 탭을 오가도 상태가 남는다. 라우터 없음(푸시 화면은 알람 편집 · 울림 둘).

| 화면 | 들어가는 곳 | 내용 |
|---|---|---|
| 걷기 `WalkHomePage` | 걷기 탭 | 오늘 카드(걸음 크게 · km · kcal) → `주간` · `월간` 탭 → 기간 머리(‹ ›) → 막대그래프(오늘 강조, 탭하면 값) → 요약(합계 · 일평균 · 거리 · 칼로리) |
| 알람 목록 `AlarmListPage` | 알람 탭 | 권한 경고 배너 → **요약 카드**(다음 알람까지 `N시간 M분 후` · `내일 (화) 오전 7:00 · 라벨`) → 알람 행(시각 · 라벨 · 반복 요약 · 남은 시간 · 스위치) → FAB `+` |
| 알람 편집 `AlarmEditPage` | 행 탭 · FAB | 시각 휠 · 요일 토글 7개(한 줄) · 라벨(30자) · 진동 · 저장 · 삭제(수정일 때, 확인 다이얼로그) |
| 울림 `AlarmRingingPage` | 알람이 울릴 때 | 큰 현재 시각 · 라벨 · [5분 뒤 다시 울림] · [알람 끄기]. 뒤로가기로 닫히지 않는다 |
| 설정 `SettingsPage` | 설정 탭 | 권한(알림 · 정확한 알람 · 전체 화면 알림 · Health Connect) 상태와 설정 이동 · 테마(시스템/라이트/다크) · 버전 · 오픈소스 라이선스 · 14일 안내 |

### 걷기

- 접근 상태(Health Connect 없음 · 업데이트 필요 · 권한 없음)는 탭 전체를 `AppPlaceholder` 로 대신하고
  설치 · 권한 요청 버튼을 준다.
- 앱 열 때 · 백그라운드 복귀 때 · 당겨서 새로고침 때 다시 읽는다.
- 거리 · 칼로리가 Health Connect 에 없으면 `–`. 계산하지 않는다.

### 알람

- 알람 정의는 벽시계 시각(시 · 분 · 반복 요일)으로 저장한다. 반복이 없으면 1회성.
- 앞으로 **14일 안의 회차를 미리 예약**하고, 앱 시작 · 복귀 · 저장/삭제/토글 · 울림 뒤에 다시 맞춘다
  (`sync`). 그래서 앱을 14일 넘게 열지 않으면 반복 알람이 멈출 수 있다(설정 탭 안내).
- 남은 시간은 **실제로 예약된 다음 울림** 기준이다(스누즈 포함). 분 단위, 올림. 매분 0초에 갱신.
- 울림:
  - 화면 꺼짐 · 잠금 → 전체 화면 울림 화면
  - 폰 사용 중(다른 앱이 앞) → 상단 헤드업 알림에 같은 두 버튼
  - 이 앱이 앞 → 앱 안에서 울림 화면
- 스누즈는 5분 고정. 울리는 중 앱을 최근 앱에서 밀어도 계속 울린다.
- 재부팅 뒤에는 패키지가 예약을 되살린다. 시간대가 바뀌면 수신기가 예약을 새 시간대의 같은 벽시계
  시각으로 옮긴다.
- 권한은 알람을 처음 저장/켤 때 묻는다(알림 → 정확한 알람). 거부해도 저장하고 경고 배너를 둔다.
- 저장값이 깨졌으면 읽을 수 있는 알람만 살리고 원본은 백업 키에 남긴다.

## 완료 조건

걷기

- [ ] 실제 폰에서 첫 실행 → 권한 허용 → 오늘 걸음이 헬스 앱과 같은 숫자로 보인다
- [x] 주간(월~일) · 월간 막대그래프와 합계 · 일평균이 맞고, 이전 기간으로 넘길 수 있다
- [ ] 거리 · 활동 칼로리가 있으면 보이고 없으면 `–`
- [x] 권한 거부 · Health Connect 없음이 안내 화면으로 이어지고 재시도로 풀린다
- [ ] 백그라운드에서 돌아오면 갱신되고, 자정을 넘겨 돌아오면 오늘이 새 날짜다

알람 · 설정

- [x] 알람을 저장하면 정한 시각에 잠금 화면 위 전체 화면으로 울리고, 끄기 · 5분 뒤가 동작한다 (에뮬레이터)
- [x] 폰 사용 중에는 헤드업 알림에 두 버튼이 보이고 스누즈 뒤에도 1회성 스위치가 켜진 채 남는다 (에뮬레이터)
- [x] 재부팅 뒤 예약이 남는다 (에뮬레이터)
- [x] 시간대를 바꾸면 앱이 꺼져 있어도 · 떠 있어도 같은 벽시계 시각으로 옮겨진다 (에뮬레이터)
- [x] 요약 카드 · 행 남은 시간이 스위치와 매분 경계에 맞춰 바뀐다 (에뮬레이터)
- [x] 테마 선택이 즉시 반영되고 다시 켜도 유지된다
- [ ] 실제 폰(PIN 잠금)에서 울림 화면이 잠금 위에 뜬다
- [x] `flutter analyze` 0 · `flutter test` 통과 · `package_boundary_test` 통과

## 범위 밖

걷기: 목표 걸음 수 · 연간 보기 · 걸음 알림 · 홈 화면 위젯 · 키/몸무게 기반 추정 · 기록 쓰기.

알람: 알람음 선택 · 스누즈 간격 설정 · 걸음과 연동(걸어서 끄기 등) · 카드 탭 동작 · 스누즈 표시 배지 ·
초 단위 카운트다운 · 사용 중에도 전체 화면 강제.
