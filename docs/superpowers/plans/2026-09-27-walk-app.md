## Global Constraints

- 안드로이드만. `minSdk = 26`, `MainActivity` 는 `FlutterFragmentActivity`.
- 기존 패키지는 `core` · `design_system` · `l10n` · `permission` 만 의존. `feature_*` · `supabase_flutter` 금지(`test/convention/package_boundary_test.dart` 가 검사).
- 거리 · 칼로리는 Health Connect 값만. 없으면 `–`(U+2013). **추정 계산 금지.**
- 칼로리 타입은 `HealthDataType.ACTIVE_ENERGY_BURNED`, 거리는 `DISTANCE_DELTA`, 걸음은 `STEPS`.
- 한 주는 월요일 ~ 일요일. 날짜 경계는 기기 로컬 자정. 날짜 산술은 `DateTime(y, m, d + n)` 생성자로 한다(`Duration` 덧셈 금지).
- UI 는 CLAUDE.md "UI 공통 위젯 규칙"을 따른다 — `AppPlaceholder` · `AppButton` · `AppSpacing` · `AppRadius` · `Theme.of(context)`. `Colors.*` · 숫자 여백 · `BorderRadius.circular(n)` 직접 금지.
- Freezed 는 CLAUDE.md 두 패턴만(단일 = Primary Constructor + `@override final`, 상태 = sealed union). 분기는 `switch`.
- 문자열은 `packages/l10n/lib/l10n/app_{ko,en,ja}.arb` 에 `walk` 접두사로. 생성 파일은 손으로 고치지 않는다.
- **커밋 규칙**: 작업 트리에 다른 작업(commute 이동)이 스테이징돼 있을 수 있다. 커밋은 항상 `git add <경로들> && git commit -m "…" -- <같은 경로들>` 로 **경로를 지정**해 그 작업을 섞지 않는다. 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **`packages/permission` 은 다른 세션의 작업이다(작업 트리에 있고 아직 커밋 전).** 읽고 쓰기만 하고 수정 · `git add` 하지 않는다. `lib/data/health/health_gateway.dart`:

```dart
import 'package:flutter/services.dart';
import 'package:health/health.dart';
import 'package:injectable/injectable.dart';

/// `health` 패키지를 얇게 감싼다. 플랫폼 호출이라 mock 하기 어려운 것을 이 뒤로
/// 숨겨 repository 를 단위 테스트한다 (commute 의 `LocationGateway` 와 같은 이유).
abstract interface class HealthGateway {
  /// Health Connect 상태. 알 수 없으면 null.
  Future<HealthConnectSdkStatus?> sdkStatus();

  /// 플레이스토어의 Health Connect 설치 · 업데이트 화면을 연다.
  Future<void> installHealthConnect();

  Future<bool> hasPermission(HealthDataType type);

  /// 읽기 권한 요청 화면을 띄운다.
  Future<bool> requestPermissions(List<HealthDataType> types);

  /// 30일보다 오래된 기록 읽기 권한. 이미 있으면 묻지 않는다.
  Future<bool> requestHistoryPermission();

  /// Health Connect 의 앱 권한 설정 화면을 연다(두 번 거부하면 다이얼로그가 안 뜨므로).
  Future<void> openHealthConnectSettings();

  /// 로컬 자정인 [dayStart] 부터 하루 동안 [types] 별 합계. 기록이 없는 type 은 키가 없다.
  Future<Map<HealthDataType, double>> dayTotals(
    DateTime dayStart,
    List<HealthDataType> types,
  );
}

@LazySingleton(as: HealthGateway)
class HealthPluginGateway implements HealthGateway {
  static const _channel = MethodChannel('com.karma.walk/health_connect');

  final Health _health = Health();
  Future<void>? _configured;

  Future<void> _ready() => _configured ??= _health.configure();

  @override
  Future<HealthConnectSdkStatus?> sdkStatus() async {
    await _ready();
    return _health.getHealthConnectSdkStatus();
  }

  @override
  Future<void> installHealthConnect() async {
    await _ready();
    await _health.installHealthConnect();
  }

  @override
  Future<bool> hasPermission(HealthDataType type) async {
    await _ready();
    return await _health.hasPermissions([type]) ?? false;
  }

  @override
  Future<bool> requestPermissions(List<HealthDataType> types) async {
    await _ready();
    return _health.requestAuthorization(types);
  }

  @override
  Future<bool> requestHistoryPermission() async {
    await _ready();
    if (await _health.isHealthDataHistoryAuthorized()) return true;
    return _health.requestHealthDataHistoryAuthorization();
  }

  @override
  Future<void> openHealthConnectSettings() =>
      _channel.invokeMethod<void>('openSettings');

  @override
  Future<Map<HealthDataType, double>> dayTotals(
    DateTime dayStart,
    List<HealthDataType> types,
  ) async {
    await _ready();
    final dayEnd = DateTime(dayStart.year, dayStart.month, dayStart.day + 1);
    // 하루짜리 구간을 하루 크기 버킷 하나로 묻는다. interval 단위 문서가 엇갈려도
    // (초 / 분) 구간이 하루라 버킷이 하나로 나온다 — 그래도 여러 개면 더한다.
    final points = await _health.getHealthIntervalDataFromTypes(
      startDate: dayStart,
      endDate: dayEnd,
      types: types,
      interval: 86400,
    );
    final totals = <HealthDataType, double>{};
    for (final point in points) {
      final value = point.value;
      if (value is! NumericHealthValue) continue;
      final amount = value.numericValue.toDouble();
      totals.update(point.type, (sum) => sum + amount, ifAbsent: () => amount);
    }
    return totals;
  }
}
```

import 'period_kind.dart';

typedef PeriodRange = ({DateTime start, DateTime end});

DateTime dateOnly(DateTime t) => DateTime(t.year, t.month, t.day);

/// [offset] 0 = [now] 가 속한 기간, -1 = 그 전 기간. 주는 월요일에 시작한다.
/// `end` 는 기간의 마지막 날(포함).
PeriodRange periodRange(PeriodKind kind, int offset, DateTime now) {
  final today = dateOnly(now);
  switch (kind) {
    case PeriodKind.week:
      final start = DateTime(
        today.year,
        today.month,
        today.day - (today.weekday - DateTime.monday) + 7 * offset,
      );
      return (start: start, end: DateTime(start.year, start.month, start.day + 6));
    case PeriodKind.month:
      final start = DateTime(today.year, today.month + offset);
      return (start: start, end: DateTime(start.year, start.month + 1, 0));
  }
}

List<DateTime> daysBetween(DateTime start, DateTime end) => [
  for (
    var day = dateOnly(start);
    !day.isAfter(end);
    day = DateTime(day.year, day.month, day.day + 1)
  )
    day,
];

import 'package:freezed_annotation/freezed_annotation.dart';

import 'daily_activity.dart';
import 'period_kind.dart';

part 'activity_period.freezed.dart';

@freezed
class ActivityPeriod with _$ActivityPeriod {
  @override
  final PeriodKind kind;
  @override
  final DateTime start;

  /// 마지막 날(포함).
  @override
  final DateTime end;

  /// 계산 기준일(자정). 일평균 · 강조 · 다음 버튼이 이것을 본다.
  @override
  final DateTime today;

  /// [start]..[end] 모든 날. 기록이 없거나 오늘 이후인 날은 0보.
  @override
  final List<DailyActivity> days;

  const ActivityPeriod({
    required this.kind,
    required this.start,
    required this.end,
    required this.today,
    required this.days,
  });

  int get totalSteps => days.fold(0, (sum, day) => sum + day.steps);

  int get averageSteps {
    final elapsed = days.where((day) => !day.date.isAfter(today)).toList();
    if (elapsed.isEmpty) return 0;
    return (elapsed.fold(0, (sum, day) => sum + day.steps) / elapsed.length)
        .round();
  }

  double? get totalDistanceMeters => _sumPresent(days.map((d) => d.distanceMeters));

  double? get totalActiveKcal => _sumPresent(days.map((d) => d.activeKcal));

  bool get isCurrent => !today.isBefore(start) && !today.isAfter(end);

  static double? _sumPresent(Iterable<double?> values) {
    final present = values.whereType<double>();
    if (present.isEmpty) return null;
    return present.fold<double>(0, (sum, v) => sum + v);
  }
}

import 'package:core/core.dart';
import 'package:injectable/injectable.dart';

import '../clock.dart';
import '../entity/activity_period.dart';
import '../entity/daily_activity.dart';
import '../entity/health_access.dart';
import '../entity/period_kind.dart';
import '../entity/period_range.dart';
import '../repository/activity_repository.dart';

abstract interface class WalkUseCase {
  Future<HealthAccess> access();

  Future<HealthAccess> requestAccess();

  bool get permissionDeclinedThisSession;

  Future<void> openPermissionSettings();

  Future<void> openInstall();

  Future<Result<DailyActivity>> today();

  /// [offset] 0 = 현재 기간, -1 = 그 전 기간.
  Future<Result<ActivityPeriod>> period(PeriodKind kind, int offset);
}

@LazySingleton(as: WalkUseCase)
class DefaultWalkUseCase implements WalkUseCase {
  DefaultWalkUseCase(this._repository, this._clock);

  final ActivityRepository _repository;
  final Clock _clock;

  @override
  Future<HealthAccess> access() => _repository.access();

  @override
  Future<HealthAccess> requestAccess() => _repository.requestAccess();

  @override
  bool get permissionDeclinedThisSession =>
      _repository.permissionDeclinedThisSession;

  @override
  Future<void> openPermissionSettings() => _repository.openPermissionSettings();

  @override
  Future<void> openInstall() => _repository.openInstall();

  @override
  Future<Result<DailyActivity>> today() async {
    final today = dateOnly(_clock.now());
    final result = await _repository.dailyActivities(today, today);
    return switch (result) {
      Ok(value: final days) => Ok(days.isEmpty ? DailyActivity.empty(today) : days.first),
      Err(:final failure) => Err(failure),
    };
  }

  @override
  Future<Result<ActivityPeriod>> period(PeriodKind kind, int offset) async {
    final today = dateOnly(_clock.now());
    final range = periodRange(kind, offset, today);
    final readUntil = range.end.isAfter(today) ? today : range.end;
    final result = await _repository.dailyActivities(range.start, readUntil);
    return switch (result) {
      Ok(value: final read) => Ok(
        ActivityPeriod(
          kind: kind,
          start: range.start,
          end: range.end,
          today: today,
          days: [
            ...read,
            for (final day in daysBetween(range.start, range.end))
              if (day.isAfter(readUntil)) DailyActivity.empty(day),
          ],
        ),
      ),
      Err(:final failure) => Err(failure),
    };
  }
}

/// 걸음 권한 기준. Health Connect 는 두 번 거부하면 다이얼로그를 조용히 생략할 뿐
/// 구분해 주지 않으므로 [PermissionStatus.permanentlyDenied] 는 돌려주지 않는다
/// (permission 설계 §2) — 화면은 `declinedThisSession` 으로 "설정 열기"를 보인다.
class HealthPermissionSource implements PermissionSource {
  HealthPermissionSource(this._gateway);

  final HealthGateway _gateway;

  static const readTypes = [
    HealthDataType.STEPS,
    HealthDataType.DISTANCE_DELTA,
    HealthDataType.ACTIVE_ENERGY_BURNED,
  ];

  @override
  Future<PermissionStatus> check() async =>
      await _gateway.hasPermission(HealthDataType.STEPS)
          ? PermissionStatus.granted
          : PermissionStatus.denied;

  @override
  Future<PermissionStatus> request() async {
    await _gateway.requestPermissions(readTypes);
    final status = await check();
    // 걸음을 허용한 사람에게만 30일 이전 기록을 묻는다. 거부하면 그 이전 기간이 0으로 보일 뿐이다.
    if (status == PermissionStatus.granted) await _gateway.requestHistoryPermission();
    return status;
  }

  @override
  Future<void> openSettings() => _gateway.openHealthConnectSettings();
}

@LazySingleton(as: ActivityRepository)
class HealthConnectActivityRepository implements ActivityRepository {
  HealthConnectActivityRepository(this._gateway)
    : _permission = PermissionRequester(HealthPermissionSource(_gateway));

  final HealthGateway _gateway;

  /// 세션 기억("이번 세션에 거부했다")을 가진다. 저장소가 싱글턴이라 앱 수명 동안 하나다.
  final PermissionRequester _permission;

  static const _steps = HealthDataType.STEPS;
  static const _distance = HealthDataType.DISTANCE_DELTA;
  static const _kcal = HealthDataType.ACTIVE_ENERGY_BURNED;

  @override
  Future<HealthAccess> access() async {
    try {
      return switch (await _gateway.sdkStatus()) {
        HealthConnectSdkStatus.sdkAvailable => _toAccess(await _permission.ensure()),
        HealthConnectSdkStatus.sdkUnavailableProviderUpdateRequired =>
          HealthAccess.updateRequired,
        HealthConnectSdkStatus.sdkUnavailable || null => HealthAccess.notInstalled,
      };
    } on Object {
      return HealthAccess.permissionDenied;
    }
  }

  @override
  Future<HealthAccess> requestAccess() async {
    try {
      await _permission.requestAgain();
    } on Object {
      // 취소 · 플랫폼 오류도 여기로 온다. 결과는 아래 확인이 정한다.
    }
    // access() 는 ensure() 라 방금 거부했으면 다시 묻지 않는다.
    return access();
  }

  @override
  bool get permissionDeclinedThisSession => _permission.declinedThisSession;

  @override
  Future<void> openPermissionSettings() => _permission.openSettings();

  @override
  Future<void> openInstall() => _gateway.installHealthConnect();

  @override
  Future<Result<List<DailyActivity>>> dailyActivities(
    DateTime from,
    DateTime to,
  ) async {
    try {
      // 거리 · 칼로리 권한만 거부됐으면 그 타입을 묻지 않는다 — 물으면 예외가 난다.
      final types = [
        _steps,
        if (await _gateway.hasPermission(_distance)) _distance,
        if (await _gateway.hasPermission(_kcal)) _kcal,
      ];
      final days = daysBetween(from, to);
      final totals = await Future.wait(
        days.map((day) => _gateway.dayTotals(day, types)),
      );
      return Ok([
        for (var i = 0; i < days.length; i++)
          DailyActivity(
            date: days[i],
            steps: (totals[i][_steps] ?? 0).round(),
            distanceMeters: totals[i][_distance],
            activeKcal: totals[i][_kcal],
          ),
      ]);
    } on Object catch (e) {
      return Err(Failure.unknown(message: '걸음 기록을 읽지 못했다: $e'));
    }
  }

  static HealthAccess _toAccess(PermissionStatus status) => switch (status) {
    PermissionStatus.granted => HealthAccess.granted,
    PermissionStatus.denied ||
    PermissionStatus.permanentlyDenied => HealthAccess.permissionDenied,
  };
}

import 'package:intl/intl.dart';

/// 숫자 · 날짜 표기를 한곳에 둔다. 값이 없으면 [missing] — 계산해서 채우지 않는다.
abstract final class WalkFormat {
  static const missing = '–';

  static String steps(String locale, int steps) =>
      NumberFormat.decimalPattern(locale).format(steps);

  static String distance(String locale, double? meters) => meters == null
      ? missing
      : '${NumberFormat('0.0', locale).format(meters / 1000)} km';

  static String kcal(String locale, double? kcal) => kcal == null
      ? missing
      : '${NumberFormat.decimalPattern(locale).format(kcal.round())} kcal';

  static String weekRange(String locale, DateTime start, DateTime end) {
    final format = DateFormat.MMMd(locale);
    return '${format.format(start)} – ${format.format(end)}';
  }

  static String month(String locale, DateTime start) =>
      DateFormat.yMMMM(locale).format(start);

  static String weekday(String locale, DateTime day) =>
      DateFormat.E(locale).format(day);

  static String day(DateTime day) => '${day.day}';
}

import 'package:flutter_bloc/flutter_bloc.dart';

import '../../domain/entity/period_kind.dart';
import '../../domain/usecase/walk_use_case.dart';

class PeriodActivityCubit extends Cubit<PeriodActivityState> {
  PeriodActivityCubit(this._useCase, this.kind)
    : super(const PeriodActivityState.loading(0));

  final WalkUseCase _useCase;
  final PeriodKind kind;
  int _generation = 0;

  int get _offset => switch (state) {
    PeriodActivityLoading(:final offset) ||
    PeriodActivityLoaded(:final offset) ||
    PeriodActivityFailure(:final offset) => offset,
  };

  Future<void> load() => _read(_offset, showLoading: true);

  Future<void> refresh() => _read(_offset, showLoading: false);

  Future<void> previous() => _read(_offset - 1, showLoading: true);

  /// 현재 기간(offset 0)보다 미래로는 가지 않는다.
  Future<void> next() {
    if (_offset >= 0) return Future.value();
    return _read(_offset + 1, showLoading: true);
  }

  Future<void> _read(int offset, {required bool showLoading}) async {
    final generation = ++_generation;
    if (showLoading) emit(PeriodActivityState.loading(offset));
    final result = await _useCase.period(kind, offset);
    if (isClosed || generation != _generation) return;
    emit(switch (result) {
      Ok(value: final period) => PeriodActivityState.loaded(offset, period),
      Err(:final failure) => PeriodActivityState.failure(offset, failure),
    });
  }
}

  static const _chartHeight = AppSpacing.xl * 5;

  @override
  State<ActivityBarChart> createState() => _ActivityBarChartState();

class _ActivityBarChartState extends State<ActivityBarChart> {
  DailyActivity? _selected;

  @override
  void didUpdateWidget(ActivityBarChart oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.period.start != widget.period.start) _selected = null;
  }

  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context);
    final locale = l10n.localeName;
    final period = widget.period;
    final maxSteps = period.days.fold(0, (m, d) => d.steps > m ? d.steps : m);

    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        SizedBox(
          key: const Key('walk-bar-selection'),
          height: AppSpacing.lg,
          child: selected == null
              ? null
              : Text(
                  '${DateFormat.MMMEd(locale).format(selected.date)} · '
                  '${l10n.walkStepsCount(WalkFormat.steps(locale, selected.steps))}',
                  textAlign: TextAlign.center,
                  style: Theme.of(context).textTheme.labelLarge,
                ),
        ),
        SizedBox(
          height: ActivityBarChart._chartHeight,
          child: Row(
            crossAxisAlignment: CrossAxisAlignment.end,
            children: [
              for (final day in period.days)
                Expanded(child: _bar(context, day, maxSteps)),
            ],
          ),
        ),
        const SizedBox(height: AppSpacing.xs),
        Row(
          children: [
            for (final day in period.days)
              Expanded(
                child: Text(
                  _label(locale, day.date),
                  textAlign: TextAlign.center,
                  style: Theme.of(context).textTheme.labelSmall,
                ),
              ),
          ],
        ),
      ],
    );
  }

  Widget _bar(BuildContext context, DailyActivity day, int maxSteps) {
    if (day.date.isAfter(widget.period.today)) return const SizedBox.shrink();
    final scheme = Theme.of(context).colorScheme;
    final isToday = day.date == widget.period.today;
    final isSelected = day.date == _selected?.date;
    final ratio = maxSteps == 0 ? 0.0 : day.steps / maxSteps;

    return GestureDetector(
      behavior: HitTestBehavior.opaque,
      onTap: () => setState(() => _selected = day),
      child: Align(
        alignment: Alignment.bottomCenter,
        child: FractionallySizedBox(
          heightFactor: ratio.clamp(0.02, 1.0),
          child: Container(
            key: Key('walk-bar-${DateFormat('yyyy-MM-dd').format(day.date)}'),
            margin: const EdgeInsets.symmetric(horizontal: AppSpacing.xs / 2),
            decoration: BoxDecoration(
              color: isToday || isSelected ? scheme.primary : scheme.primaryContainer,
              borderRadius: const BorderRadius.vertical(
                top: Radius.circular(AppRadius.sm / 2),
              ),
            ),
          ),
        ),
      ),
    );
  }

  /// 주간은 요일, 월간은 1 · 5 · 10 · 15 · 20 · 25 · 30 일만(좁아서).
  String _label(String locale, DateTime date) => switch (widget.period.kind) {
    PeriodKind.week => WalkFormat.weekday(locale, date),
    PeriodKind.month =>
      date.day == 1 || date.day % 5 == 0 ? WalkFormat.day(date) : '',
  };
}

class _WalkHomePageState extends State<WalkHomePage> {
  final _useCase = getIt<WalkUseCase>();
  late final _access = HealthAccessCubit(_useCase)..check();
  late final _today = TodayActivityCubit(_useCase);
  late final _week = PeriodActivityCubit(_useCase, PeriodKind.week);
  late final _month = PeriodActivityCubit(_useCase, PeriodKind.month);
  late final AppLifecycleListener _lifecycle;
  PeriodKind _kind = PeriodKind.week;

  @override
  void initState() {
    super.initState();
    _lifecycle = AppLifecycleListener(onResume: _onResume);
  }

  @override
  void dispose() {
    _lifecycle.dispose();
    _access.close();
    _today.close();
    _week.close();
    _month.close();
    super.dispose();
  }

  Future<void> _onResume() async {
    await _access.check();
    if (_access.state.access == HealthAccess.granted) await _refresh();
  }

  void _load() {
    _today.load();
    _week.load();
    _month.load();

  Future<void> _refresh() => Future.wait([
    _today.refresh(),
    _week.refresh(),
    _month.refresh(),
  ]);

  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context);
    return Scaffold(
      appBar: AppBar(title: Text(l10n.walkAppTitle)),
      body: BlocConsumer<HealthAccessCubit, HealthAccessState>(
        bloc: _access,
        listenWhen: (previous, current) =>
            previous.access != HealthAccess.granted &&
            current.access == HealthAccess.granted,
        listener: (_, _) => _load(),
        builder: (context, state) => switch (state.access) {
          null => const Center(child: CircularProgressIndicator()),
          HealthAccess.notInstalled => Center(
            child: AppPlaceholder(
              icon: Icons.health_and_safety_outlined,
              message: l10n.walkHealthConnectMissing,
              description: l10n.walkHealthConnectMissingDescription,
              actionLabel: l10n.walkInstall,
              onAction: _access.openInstall,
            ),
          ),
          HealthAccess.updateRequired => Center(
            child: AppPlaceholder(
              icon: Icons.system_update_outlined,
              message: l10n.walkHealthConnectUpdate,
              actionLabel: l10n.walkUpdate,
              onAction: _access.openInstall,
            ),
          ),
          HealthAccess.permissionDenied => Center(
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [

                  message: l10n.walkPermissionNeeded,

            ),
          ),
          HealthAccess.granted => _dashboard(l10n),
        },
      ),
    );

              padding: EdgeInsets.all(AppSpacing.xl),
              child: Center(child: CircularProgressIndicator()),
            ),
            TodayActivityFailure() => AppPlaceholder(
              message: l10n.walkLoadFailed,

            TodayActivityLoaded(:final activity) =>

          cubit: switch (_kind) {
            PeriodKind.week => _week,
            PeriodKind.month => _month,
          },
