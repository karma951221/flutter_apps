# Life Log 설정 탭 · 프로필 — 설계

- 날짜: 2026-11-17
- 앱: `apps/walk` (Life Log)
- 상태: 승인(2026-11-17)

## 의도

실사용 QA: "설정값이 탭마다 흩어져 있다. 하단 탭이 셋뿐이니 설정 탭을 하나 더 두자. 기능 화면에서
바로 바꾸는 게 편한 설정 말고 앱 전역 설정을 보는 탭. 내 사진 · 프로필도 넣자."

지금도 전역 설정을 모은 "앱 설정" 화면(`AppSettingsPage`)은 있다. 다만 각 탭 ⋮ 맨 아래에만 있어서
찾기 어렵다. 이 화면을 하단 넷째 탭으로 올리고, 전역 항목과 프로필을 더한다.

## 지금 설정 · 진입점 (2026-11-17 main 기준)

| 탭 › 화면 | ⋮ 메뉴 | 설정 화면 내용 | 잠금 |
|---|---|---|---|
| 도구 › 알람 | 알람 기록 · 알람 설정 · 앱 설정 | 공휴일 알림 · 공휴일 출처, 권한(알림 · 정확한 알람 · 전체 화면) | 밖 |
| 도구 › 걷기 | 걷기 설정 · 앱 설정 | 하루 걸음 목표, Health Connect 권한 | 밖 |
| 도구 › 날씨 | 앱 설정 | — | 밖 |
| 기록 › 일기 | 스토리 · 휴지통 · 일기 설정 · 앱 설정 (잠기면 앱 설정만) | 휴지통 보관 · 저장 공간 · 자동 초안 | 아래 |
| 기록 › 지도 | 지도 설정 · 앱 설정 (잠기면 앱 설정만) | 위치 기록 · 촘촘 기록 · 보관 기간 · 지도 스타일 · 배터리 · 권한 · 모두 지우기 | 아래 |
| 물어보기 | 대화 목록 · 위키 · 작업 폴더 · 정리 · 임시 대화 · 물어보기 설정 · 앱 설정 | AI 연결 · 키 · 모델, 대화 보관 · 사용량 · 위키 크기 · 모두 지우기 | 아래 |
| (⋮ › 앱 설정) | | 잠금(PIN · 패턴 · 다시 잠금), 테마, 위 6개 화면 + 백업 바로가기 | 밖 |

그 밖의 진입점: 알람 탭 권한 안내 → 알람 설정(강조), 물어보기 연결 안내 · 일기 작성 시트 → 물어보기
설정(강조, `settingsOpener`). 언어 설정은 없다(시스템 언어를 따른다).

## 목표

1. 하단 탭을 **도구 · 기록 · 물어보기 · 설정** 넷으로 둔다. 설정은 맨 끝, 아이콘은
   `Icons.settings_outlined` / `Icons.settings`.
2. 설정 탭이 기존 앱 설정 화면을 대신한다. 잠금 밖이고, 잠겨 있어도 열린다.
3. 프로필(사진 · 이름 · 한 줄 소개)을 만들고 설정 탭 머리에 보인다.
4. 프로필 이름을 물어보기에 보낼지 고르는 토글을 둔다. 기본은 끔이다(사용자 결정).
5. 백업의 "앱 설정" 영역에 프로필(이름 · 소개 · 사진)을 담는다.

## 하지 않는 것

- 언어 설정. 앱 문구 · 프롬프트가 사실상 한국어 전용이라 시스템을 따른다.
- 일기 피드 · 카드의 작성자 표시. 혼자 쓰는 기록이라 카드마다 같은 얼굴이 붙으면 소음이 된다.
- 권한을 한곳에 모은 화면. 권한 행은 지금처럼 기능 설정 화면에 둔다.
- 사진 자르기 · 필터. 고른 사진을 정사각으로 가운데만 보여 준다(`CircleAvatar` 기본).
- 기능 설정 화면 내용의 재배치. 각 화면은 그대로 두고, 진입점만 정리한다.
- 지도 설정 화면의 촘촘 기록 행 수정. 이름 · 토글은 `walk-dense-toggle` 세션이 맡는다.

## 실패로 칠 것

- 잠긴 상태에서 설정 탭을 거쳐 일기 · 물어보기 · 지도 설정(잠금 아래)이 열린다.
- 토글을 끈 상태에서 이름이 AI 요청에 실린다.
- 복원 뒤 프로필 사진 경로가 가리키는 파일이 없다.

## 접근 방식

1. **기존 앱 설정 화면을 탭 본문으로 옮긴다 (채택).** `AppSettingsPage` 를 `SettingsTab` 으로 바꾸고
   셸 `IndexedStack` 넷째 자식으로 둔다. 셸이 이미 설정 cubit 다섯을 내려 주므로 `openSettings` 를
   그대로 부를 수 있다. 바뀌는 곳이 셸 · 앱 설정 · ⋮ 뿐이다.
2. 설정 탭에 각 기능 설정 내용을 모두 펼친다. 화면 하나가 매우 길어지고, 잠금 아래 내용(일기 · 물어보기 ·
   지도)을 잠금 밖에 펼칠 수 없다. 기능 화면 쪽 "바로 바꾸는 설정"이라는 의도와도 어긋난다.
3. 하단 탭은 셋으로 두고 앱바에 프로필 아바타를 둬 설정을 연다. 사용자가 넷째 탭을 원했다.

## 설계

### 설정 탭 화면

```
설정
┌───────────────────────────────┐
│ (사진)  이름 / "프로필 만들기"      › │  ← 누르면 프로필 편집
│         한 줄 소개                  │
├ 화면 ─────────────────────────┤
│ ○ 시스템  ○ 라이트  ○ 다크           │
├ 보안 ─────────────────────────┤
│ 잠금 · 다시 잠금 (기존 LockSettingsSection) │
├ 데이터 ───────────────────────┤
│ 백업 · 복원                        › │
├ 연결 · 기록 ──────────────────┤
│ AI 연결 (물어보기 설정)   Claude 연결됨 › │  ← 잠금 거침
│ 위치 기록               켜짐 · 촘촘   › │  ← 지도 설정(잠금 거침)
├ 기능별 설정 ───────────────────┤
│ 일기 설정 / 알람 설정 / 걷기 설정      › │
├ 앱 정보 ───────────────────────┤
│ 오픈소스 라이선스                    › │
└───────────────────────────────┘
```

- 앱바 제목 "설정", ⋮ 없음.
- AI 연결 행 부제는 연결 상태(연결됨 · 연결 안 됨)만 보인다. 키 값은 보이지 않는다. 상태를 읽을 수 없거나
  잠금 때문에 모르면 부제를 생략한다(구현자 판단).
- 위치 기록 행 부제는 `MapRecordCubit` 상태로 "꺼짐" · "켜짐" · "켜짐 · 촘촘" · "멈춤(권한)"을 보인다.
  촘촘 기록은 행이 여는 지도 설정 화면에서 바꾼다. `walk-dense-toggle` 이 바꾼 이름을 따른다.
- 오픈소스 라이선스는 Flutter `showLicensePage`(앱 이름 Life Log).
- 탭이 다시 보일 때(탭 전환 · 위 화면이 닫힐 때) 잠금 상태 · 연결 상태 · 위치 기록 상태를 다시 읽는다.

### 원본과 바로가기

| 설정 | 원본 | 다른 진입점 |
|---|---|---|
| 프로필 · 테마 · 잠금 · 백업 · 라이선스 | 설정 탭 | — |
| AI 연결 · 대화 기록 (물어보기 설정) | 물어보기 ⋮ › 물어보기 설정 | 설정 탭 "AI 연결" |
| 위치 기록 · 촘촘 기록 · 보관 · 스타일 (지도 설정) | 기록 › 지도 ⋮ › 지도 설정 | 설정 탭 "위치 기록" |
| 일기 · 알람 · 걷기 설정 | 각 탭 ⋮ | 설정 탭 "기능별 설정" |

### ⋮ 메뉴 정리

- 모든 `FeatureMenu` 에서 "앱 설정" 항목을 뺀다. `SettingsTarget.app` 은 없앤다.
- 항목이 하나도 없으면 ⋮ 자체를 그리지 않는다. 날씨와, 잠긴 동안의 일기 · 지도 · 물어보기가 해당한다.
- 물어보기 탭 연결 안내 · 알람 권한 안내 · 일기 작성 시트의 바로가기는 그대로 둔다.

### 프로필

- 모델 `Profile { name, bio, photoFile, shareNameWithAi }` (Freezed primary constructor).
  - `name`: 20자 이하. 비어 있으면 "프로필 만들기"로 보인다.
  - `bio`: 60자 이하, 한 줄.
  - `photoFile`: 앱 문서 폴더 `profile/` 아래 파일 이름. 없으면 null.
  - `shareNameWithAi`: 기본 false.
- 저장소: `SharedPreferences` 키 `profile.name` · `profile.bio` · `profile.photo` ·
  `profile.shareNameWithAi`, 사진 파일은 `<문서>/profile/avatar-<millis>.jpg`.
- 편집 화면(`ProfilePage`): 큰 `AppAvatar`(누르면 시트: 갤러리에서 고르기 · 사진 찍기 · 사진 지우기),
  이름 · 소개 입력, "물어보기에 내 이름 알려주기" 스위치와 설명("켜면 대화할 때 이름이 Claude · GPT 로
  전송됩니다"), 앱바의 저장 버튼. 저장하지 않고 나가면 바뀐 게 있을 때만 버릴지 묻는다.
- 사진: 기존 `MediaPicker`(앨범 · 카메라로 나가는 동안 `MediaPickGuard` 로 다시 잠김 방지)를 쓴다.
  가로세로 512px 이하로 줄인 JPEG 사본을 저장하고, picker 캐시 사본은 지운다. 새 사진을 저장하면
  이전 파일을 지운다. 사진 메타데이터(EXIF · GPS)는 사본에 남기지 않는다.
- 아바타는 `AppAvatar(nickname: name, imageFile: …)`. 사진이 없으면 이름 첫 글자, 이름도 없으면
  사람 아이콘이다(`AppAvatar` 가 빈 이름을 어떻게 그리는지 보고 필요하면 감싼다).
- 프로필은 잠금 밖이다. 사진이 잠긴 동안에도 설정 탭 머리에 보인다.

### 물어보기에 이름 전달

- `shareNameWithAi` 가 true이고 이름이 비어 있지 않을 때만 대화 시스템 프롬프트에 한 줄을 넣는다:
  `사용자의 이름은 "<이름>" 이다. 필요할 때 이름으로 부른다.` 위치는 규약 뒤, 날짜 줄 앞이다(캐시 접두부를
  날마다 같게 유지한다).
- 소개(bio)는 보내지 않는다. 위키 정리(`WikiDistiller`) 프롬프트에도 넣지 않는다.

### 백업

- 설정 영역(`SettingsBackupArea`)이 `profile.name` · `profile.bio` 를 prefs 허용 목록에 담고, 사진 파일을
  `settings/profile/` 에 복사한다. schema 에 `profile: 1` 을 더한다.
- `profile.shareNameWithAi` 는 담지 않는다. 복원하면 꺼진 상태다. 외부 전송 동의 성격이라 키 · 동의처럼
  기기마다 다시 고른다.
- 복원: 백업에 프로필 사진이 있으면 새 파일 이름으로 복사하고 `profile.photo` 를 맞춘다. 프로필이 없는
  옛 백업(schema 에 `profile` 없음)을 복원하면 지금 프로필을 그대로 둔다.
