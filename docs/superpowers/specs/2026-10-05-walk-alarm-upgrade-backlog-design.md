# walk — 알람 고도화 백로그

> 작성 2026-10-05 · 상태: **백로그 승인** · 앱 문서 [walk 허브](../../../apps/walk/docs/README.md) ·
> 선행 설계 [기상 알람](2026-09-27-walk-alarm-design.md) · [알람음 선택](2026-10-05-walk-alarm-sound-design.md)

이 문서는 알람 고도화 **항목과 순서**만 정한다. 각 웨이브는 착수할 때 따로 설계 → 실행 계획 → 구현을
거치고, 세부 결정은 그 웨이브의 설계 문서가 단일 기준이다. 진행 상태는
[walk status](../../../apps/walk/docs/status.md) 에만 적는다.

## 1. 출발점

지금 알람(2026-10-05 기준)은 다음과 같다.

- 편집에서 정하는 것: 시각 · 반복 요일 토글 7개 · 라벨 · 진동 켬/끔. 반복이 없으면 1회성(다음 해당 시각).
- 울림: 소리는 에셋 비프 하나, 볼륨 0.8 · 3초 페이드 고정. 스누즈 5분 고정.
- 예약: 앞으로 14일 회차를 미리 걸고 앱 시작 · 복귀 · 저장 때 다시 맞춘다. 앱을 14일 넘게 안 열면
  반복 알람이 멈출 수 있다.
- 설정 탭에 버전 · 오픈소스 라이선스 행이 있다.

## 2. 결정 기록

| 결정 | 이유 |
|---|---|
| 고도화 방향은 울림 커스터마이즈 · 일정 유연성 · 신뢰성/편의. 끄기 미션(걸어서 끄기 · 문제 풀기)은 넣지 않는다 | 사용자 결정 |
| 알람음 선택은 [별도 설계](2026-10-05-walk-alarm-sound-design.md)로 먼저 진행하고, 새 편집 화면은 그 결과(`Alarm.sound` · `AlarmSoundPage`) 위에 얹는다 | 이미 승인된 설계가 있다. 두 작업이 편집 화면을 함께 고치므로 순서를 정한다 |
| `+` 를 누르면 일회성 / 반복을 먼저 고른다 | 사용자 요청. 두 알람의 시각 정하는 방식이 다르다 |
| 일회성은 "얼마 뒤"를 버튼으로 쌓아 정하고, 울릴 시각을 보여주며 그걸 눌러 시각 휠로 직접 정할 수도 있다 | 사용자 결정. "내일 아침 7시에 한 번"도 만들 수 있어야 한다 |
| 반복은 시각 휠 + [매일 · 평일 · 주말] 빠른 버튼. 요일 토글은 그대로 둔다 | 사용자 요청. 흔한 경우는 한 번에, 드문 경우는 직접 |
| 라벨은 화면에서 "제목"으로 부른다. 저장 키(`label`)는 그대로 둔다 | 사용자 요청. 저장값 이전이 필요 없다 |
| 진동 켬/끔 토글을 없애고 "무음 · 진동 모드에선 진동만" 체크박스 하나를 둔다. 진동은 항상 울린다 | 사용자 결정. 문구는 의미가 드러나게 정한다 |
| 위 체크박스는 착수 전에 스파이크로 가능 여부를 확인한다 | 안드로이드 알람(`USAGE_ALARM`)은 무음 모드를 무시하고 울리고, 소리는 `alarm` 패키지의 네이티브 서비스가 낸다. 울리는 순간 벨소리 모드를 보려면 네이티브 수정이 필요할 수 있다 |
| 설정의 버전 · 오픈소스 라이선스 행을 지운다 | 사용자 결정. 개인용 앱이라 필요 없다 |
| 날짜 지정 1회 알람은 넣지 않는다. 빠른 타이머 알람은 일회성 "얼마 뒤"에 흡수한다 | 새 일회성 흐름과 겹친다 |
| 웨이브마다 따로 설계 · 계획 · 구현한다 | 한 문서에 담기엔 서로 독립된 조각이 많다 |

## 4. 공통 영향

- `Alarm` 엔티티에 필드가 늘어난다(웨이브 0 `sound`, 웨이브 1 진동 모드 체크, 웨이브 3 볼륨 · 스누즈 ·
  건너뛰기). 저장값은 지금처럼 JSON 이고, **새 키가 없으면 기본값으로 읽는다** — 이전 작업 없이 기존
  알람이 그대로 읽혀야 한다.
- 진동 토글 → 체크박스(N5)는 기존 `vibrate` 키의 의미가 바뀐다. 기존 값 처리는 웨이브 1 설계에서 정한다.
- 각 웨이브가 끝나면 [walk plan](../../../apps/walk/docs/plan.md) 의 화면 표 · "범위 밖"을 고친다.

## 5. 순서

웨이브 0 → 1 → 3 → 4. 웨이브 2 는 독립이라 사이 어디든 끼울 수 있다.
웨이브 1 은 N5 스파이크를 먼저 하고, 결과에 따라 N5 를 웨이브 1 에 둘지 뒤로 미룰지 정한다.
