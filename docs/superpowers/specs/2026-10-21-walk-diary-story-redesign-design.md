# Life Tool 일기 — 인스타 스토리식 화면 재기획

작성 2026-10-21. 기존 설계: [일기](2026-10-10-walk-diary-design.md). 이 문서는 그 설계의 **§6.1 일기 탭 · 보기 모드 3종 · 기록 상세 · 스토리 관리 화면 · 작성 화면의 배치**를
바꾼다. 데이터(DB 스키마 · 저장소 · 유스케이스) · 잠금 · 휴지통 · 미디어 압축 · 검색 규칙은 그대로다.

## 1. 왜

사용자 피드백(2026-10-21):

- 스토리(= 기록 묶음, 예: "제주 여행")가 쌓였을 때 **스토리 목록이 자연스럽게** 보이면 좋겠다.
- 조회 화면에서 줄글 · 피드 · 릴스 토글 아래로 기록이 쌓이는 모양이 어색하다.
- 릴스를 누르면 화면이 확 바뀐다.
- 올리기 · 보기가 **인스타그램 스토리**와 비슷하면 좋겠다.

사용자는 질문 대신 "일단 알아서 만들고 피드백"을 골랐다. 아래 배치는 전부 이 문서의 판단이다(사용자 확정 아님). 만들어 본 뒤 피드백으로 고친다.

## 2. 목표 · 비목표 · 반목표

- **목표**: 인스타 홈처럼 위에 스토리 동그라미 줄, 아래에 기록 피드. 동그라미를 누르면 인스타 스토리 뷰어처럼 화면을 채운 채 탭으로 넘겨 본다.
  스토리가 많아지면 "모든 스토리"에서 표지 카드로 훑는다. 올리기는 사진부터 고르고 "어디에(어느 스토리) 올릴지"를 동그라미로 고른다.
- **비목표**: 24시간 뒤 사라짐 · 본 것/안 본 것 표시 · 공유 · 사진 위 글씨/스티커 · 음악. DB 스키마 변경 없음.
- **반목표**(이러면 실패): 보기 모드 토글이 남아 화면이 갑자기 다른 모양으로 바뀜 · 잠금이 새 화면에서 새는 것 · 기존 기록이 안 보이거나 지워지는 것.

## 3. 화면

### 3.1 일기 탭 (인스타 홈)

```text
┌───────────────────────────────┐
│ 일기                    🔍  ⋮  │  ⋮ = 모든 스토리 · 휴지통
│ (＋)  (◉제주) (◉일상) (○출장) … ›│  스토리 동그라미 줄(가로 스크롤)
│ 새 스토리 제주 여행 일상  출장  모두 보기
│───────────────────────────────│
│ (●) 제주 여행 · 애월읍         ⋮ │  피드 카드 머리: 스토리 · 장소
│ ┌───────────────────────────┐ │
│ │  사진 (좌우 넘김, 1/3)       │ │
│ └───────────────────────────┘ │
│ 노을이 예뻤다… 더 보기          │
│ #제주 #노을                    │
│ 2시간 전                       │
│ … 다음 카드                     │
│                          (＋) │
└───────────────────────────────┘
```

- **보기 모드 토글을 없앤다.** 몸통은 모든 스토리의 기록을 최신순으로 보이는 피드 하나뿐이다. "고른 스토리" 개념도 없앤다.
- **스토리 동그라미 줄**: 맨 앞 `＋ 새 스토리`(스토리 만들기 시트). 그다음 진행 중 스토리를 `lastPostedAt` 최신순으로 놓는다("일상" 포함, 기록이 없는 스토리는 뒤로).
  진행 중이면 **색 링**(primary)을 쓴다. 이어서 지난(닫힌) 스토리를 최근 종료순으로 **회색 링**을 씌워 최대 10개까지 놓는다. 끝은 `모두 보기`다.
  - 탭: 그 스토리의 **스토리 뷰어**를 연다(§3.2). 기록이 없는 스토리면 스토리 페이지(§3.3)를 연다.
  - 길게 누르기: 스토리 페이지를 연다.
- **피드 카드**: 머리에 스토리 표지 작은 원 · 스토리 이름 · 장소 이름을 둔다. 머리를 누르면 스토리 페이지로 간다. ⋮ 은 수정 · 스토리 옮기기 · 휴지통이다.
  미디어는 4:5 칸에서 좌우로 넘기고 `1/3` 표시를 붙인다. 글은 3줄에서 접고 "더 보기"를 둔다. 태그 칩을 누르면 태그 모아보기다. 상대 시각을 쓴다.
  카드 몸통을 누르면 그 기록부터 스토리 뷰어를 연다. 피드 영상은 자동재생하지 않고 썸네일 + ▶ 표시만 둔다(뷰어에서 재생).
- 비었을 때: 기존 빈 상태 안내(`AppPlaceholder`) + ＋.
- ＋(FAB)는 지금처럼 셸 Scaffold 에 둔다.

### 3.2 스토리 뷰어 (새 화면, 인스타 스토리)

```text
┌───────────────────────────────┐
│ ▬▬▬▬ ▬▬▬▬ ▭▭▭▭ ▭▭▭▭          │  그날 조각마다 진행 막대
│ (●) 제주 여행  2일차 · 10월 7일 (화) ⋮ ✕
│                               │
│        사진 / 영상 (contain)    │  화면 꽉 채움, 검은 바탕
│                               │
│ 📍 애월읍 · 오후 6:12            │  아래 그늘 위 글
│ 노을이 예뻤다. 바람이 …          │
│ #제주 #노을                     │
└───────────────────────────────┘
```

- **한 페이지 = 한 스토리의 하루.** 그날 기록들을 `occurredAt` 오름차순으로 놓고, 기록마다 미디어 하나가 조각 하나다. 미디어 없는 글 기록은 글 카드 조각 하나다.
  진행 막대는 그날 조각 수만큼 그린다. 기록이 많은 여행에서도 막대가 지나치게 잘게 쪼개지지 않게 하려는 것이다.
- **넘기기**
  - 오른쪽 2/3 탭은 다음 조각, 왼쪽 1/3 탭은 이전 조각이다.
  - 그날 마지막 조각 뒤는 다음 날이고, 스토리 마지막 날 뒤는 다음 스토리(줄 순서)다. 마지막 스토리 끝이면 닫는다.
  - 첫 조각에서 이전을 누르면 전날로, 첫날이면 이전 스토리 마지막 날로 간다.
  - 가로 스와이프는 이전/다음 **스토리**다(큐브 대신 기본 페이지 넘김).
  - 아래로 스와이프하거나 ✕ 를 누르면 닫는다.
  - 길게 누르면 멈추고 그동안 글 · 머리를 숨긴다. 손을 떼면 다시 간다.
- **시간**: 사진은 5초, 글 카드는 6초, 영상은 자기 길이(≤30초)로 소리를 켜고 한 번 재생한다. 영상을 준비하는 동안 막대는 멈춘다.
  위에 화면(수정 · 시트 · 다이얼로그)이 얹히거나 앱이 백그라운드로 가면 멈추고, 돌아오면 이어 간다.
- **시작 위치**
  - 진행 중 스토리는 **마지막 날** 첫 조각, 지난 스토리는 **첫날** 첫 조각에서 시작한다.
  - 피드 카드 · 그리드 · 검색에서 열면 그 기록의 첫 조각이다.
  - 스토리 페이지의 `▶ 처음부터 보기`는 첫날 첫 조각이다.
- **머리**: 표지 원 · 스토리 이름 · `n일차 · 날짜`(일차는 스토리 시작일 기준, "일상"은 일차 없이 날짜만) · ⋮ · ✕. 이름을 누르면 스토리 페이지로 간다.
- **⋮**(지금 조각의 기록): 수정 · 스토리 옮기기 · 휴지통으로. 휴지통으로 보내면 스낵바 되돌리기를 띄우고 다음 조각으로 넘어간다. 그날이 비면 다음 날로 간다.
- **아래 글**: 장소 · 시각 · 글 3줄(탭하면 펼치고 멈춤) · 태그. 글 기록 조각은 글 전체를 가운데 크게 보인다.
- **모아보기에서 열 때**(태그 · 장소): 스토리 대신 이름이 `#제주` / `📍 애월읍` 인 그룹 **하나**로 연다. 일 단위 페이지 규칙은 같고 가로 스와이프로 넘어갈 다른 그룹은 없다.
- 열고 닫는 전환은 페이드(갑자기 바뀌지 않게)로 한다. 다크 테마로 그린다. 잠금 경로는 `pushDiaryRoute` 다.

### 3.3 스토리 페이지 (새 화면, 인스타 프로필/하이라이트)

```text
←  제주 여행                     ⋮   ⋮ = 이름 · 표지 · 닫기/다시 열기 · 삭제
        (  표지 큰 원  )
   10월 6일 ~ 진행 중 · 기록 12 · 사진 30
   [ ▶ 처음부터 보기 ]
┌────┬────┬────┐
│ 🖼 │ ▶  │ 글 │   3열 정사각 그리드, 최신 위
└────┴────┴────┘
```

- 그리드 칸은 기록의 첫 미디어 썸네일이다. 영상이면 ▶ 표시를, 미디어가 여럿이면 겹침 아이콘을 붙인다. 글만 있는 기록은 글 앞부분 타일이다. 탭하면 그 기록부터 뷰어를 연다.
- ⋮ 동작은 기존 스토리 관리의 동작(`StoryManageCubit`: 이름 · 표지 · 닫기 · 다시 열기 · 삭제)을 그대로 옮긴다. "일상"은 닫기 · 삭제가 없다.
  삭제가 성공하면 페이지를 닫는다.
- 지난 기간으로 스토리를 만들 때 "일상" 기록 옮기기 제안은 기존 흐름 그대로 둔다(만들기 시트 쪽).

### 3.4 모든 스토리 (스토리 관리 화면을 대체)

- 머리에 ＋ 새 스토리를 둔다. 구역 **진행 중** · **지난 스토리**마다 2열 카드(정사각 표지 · 이름 · 기간 · 기록 n개)를 놓는다. 카드를 누르면 스토리 페이지(§3.3)다.
- 기존 `StoryManagePage` 의 목록 · ⋮ 는 없애고 동작은 스토리 페이지로 옮긴다.

### 3.5 태그 · 장소 모아보기

- 앱바 제목은 `#제주` / `📍 애월읍` 이다. 머리에 `기록 n개` + `▶ 보기`(그룹 첫날부터 뷰어)를 두고, 아래는 §3.3 과 같은 3열 그리드다. 칸을 누르면 그 기록부터 뷰어다.

### 3.6 올리기 (＋)

1. ＋ 를 누르면 시트 **앨범에서 · 카메라 · 영상 촬영 · 글만 쓰기**가 뜬다(기존 미디어 고르기 시트의 항목 + 글만). 고르기 취소면 아무것도 열지 않는다.
2. 작성 화면:

```text
✕  새 기록                    올리기
┌───────────────────────────┐
│ 고른 사진 큰 미리보기(좌우)    │ ＋ 칸으로 더 추가, 길게 눌러 빼기
└───────────────────────────┘
어디에 올릴까요?
(＋새) (◉제주 여행✓) (◉일상) …        진행 중 스토리 동그라미, 하나 선택
글 쓰기…
# 태그
📍 애월읍                       ✕
🕒 지금 · 10월 21일 (수) 오후 3:24 ›
```

- 미디어 · 글 · 태그 · 장소 · 시각 규칙(압축 · 임시 사본 · 시각에 맞는 스토리 제안 · 닫힌 스토리 거절)은 기존 `EntryEditorCubit` 그대로다. 배치만 바꾼다.
- 스토리 고르기는 기존 시트 대신 가로 동그라미 줄이다. `＋새`는 스토리 만들기 시트를 띄우고, 만들면 선택된다.
- 수정은 같은 화면에 기존 값을 넣어 연다(제목 "기록 고치기", 버튼 "저장"). 수정에서는 지난 스토리도 줄에 나온다(옮기기 허용 규칙 그대로).
- 올리면 닫고 스낵바 `제주 여행에 올렸어요`를 띄운다.

### 3.7 그대로 두는 것

- 검색 화면(탭 · 추천 · 강조)은 그대로다. 글 결과를 누르면 상세 대신 뷰어(그 기록)를 열고, 스토리 결과를 누르면 스토리 페이지를 연다.
- 휴지통 화면 · 설정 탭 일기 항목 · 잠금 화면 · 게이트 · 알람과의 관계는 그대로다.

## 4. 없애는 것

`DiaryViewMode` 와 prefs `viewMode` · `lastViewedStoryId`(읽지 않음; 키는 남아도 무해), `ProseView` · `ReelsView` · `ViewModeSwitch` · `DiaryEntriesView` · `StoryHeader` · `StoryBar` 의 보관함 시트 ·
`EntryDetailPage` · `StoryManagePage` 목록을 없앤다. 그것들의 테스트도 함께 없애고, 살아남는 동작(수정 · 옮기기 · 휴지통 · 스토리 관리 동작)은 새 화면 테스트로 옮긴다.

## 5. 구조 · 테스트 메모(빌더 몫)

- 뷰어의 "조각 · 날 · 그룹" 계산은 위젯 밖 순수 함수(`presentation/diary/viewer/` 또는 `domain/diary/usecase/`)로 두고 단위 테스트한다.
  그룹 목록 + 시작 기록 → (그룹, 날, 조각) 위치, 다음/이전 이동, 마지막에서 닫힘을 확인한다.
- 재생 타이머는 `AnimationController` 한 개(조각 길이)로 막대를 그리고 끝나면 다음이다. 위젯 테스트는 `pump(Duration)` 으로 자동 넘김 · 길게 눌러 멈춤 · 얹힘 멈춤을 본다.
- 영상은 기존 `VideoSurface` 를 "한 번 재생 + 끝 알림 + 재생/멈춤 제어"가 되도록 넓히거나 뷰어 전용 위젯을 둔다. 위젯 테스트는 기존처럼 `videoBuilder` 주입으로 가짜를 쓴다.
- 공통 위젯 · 토큰 규칙(CLAUDE.md)을 따른다. 진행 막대 · 스토리 링 같은 일기 전용 모양은 `presentation/diary/widget/` 에 둔다.
- l10n 문자열은 `packages/l10n` 의 기존 ARB 에 더하고, 쓰지 않게 된 키는 지운다.
- 문서: 완료 시 `apps/walk/docs/{status,history,testing}.md` 일기 절을 갱신한다. 기기 시나리오 D1~D15 중 보기 모드 · 상세에 기대던 항목(D2 · D8 · D15)의 기대 문구를 뷰어 기준으로 고친다.
