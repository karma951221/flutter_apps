# F3 post — 계획

> [문서 허브](../../README.md) · [기획 F3](../../overview.md) · [스키마](../../schema.md) · [테스트](../../testing/features/post.md)

## 범위

- 게시물 작성·수정·소프트 삭제와 단건 조회
- 작성 화면의 본문(1~500자)과 사진 최대 5장 선택·삭제
- 선택 사진은 긴 변 1080px, WebP, 품질 80으로 압축해 `post-images` Storage에 업로드
- `post_images`에 URL·가로·세로·표시 순서를 저장하고, 피드 카드에서 표시

## 화면과 상태

| 화면 | 상태 | 완료 조건 |
|---|---|---|
| 작성 | 입력, 이미지 준비, 저장 중, 실패 | 본문과 선택 이미지를 저장하고 새 `Post`를 반환한다. |
| 수정 | 입력, 저장 중, 실패 | 본문을 수정한다. 기존 첨부 이미지 편집은 후속 상세 화면 범위다. |
| 피드 카드 | 이미지 없음/있음 | 저장된 순서대로 이미지를 표시하고, 이미지가 없어도 레이아웃이 유지된다. |

## 데이터·권한

- `post_images.post_id`는 `posts`를 참조하고 게시물 삭제 시 함께 삭제한다.
- 이미지 메타데이터 조회는 살아 있는 게시물만, 쓰기는 해당 게시물 작성자만 가능하다.
- Storage 경로는 `{user_id}/{post_id}/{sort_order}.webp`이며, Storage RLS도 첫 경로 조각이 로그인 사용자와 같을 때만 쓰기를 허용한다.
